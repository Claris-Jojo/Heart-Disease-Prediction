# Heart Disease Prediction Using Logistic Regression

## Project Overview

This project uses Machine Learning to predict the presence or absence of heart disease based on patient health-related parameters.

A Logistic Regression classification algorithm is used to analyze the input data and predict whether a patient belongs to the heart disease or no heart disease category.

The project was developed using Python and Google Colab.

## Objectives

- To analyze heart disease-related patient data.
- To perform data preprocessing and feature encoding.
- To build a Logistic Regression classification model.
- To evaluate the model using classification metrics.
- To predict heart disease for sample patient data.

## Algorithm Used

### Logistic Regression

Logistic Regression is a supervised Machine Learning algorithm used for binary classification.

In this project, the model predicts one of two classes:

- Class 0: No Heart Disease
- Class 1: Heart Disease

The model estimates the probability of a patient belonging to class 1 and uses a classification threshold to generate the predicted class.

## Dataset

The dataset contains patient health-related information used to train and evaluate the model.

Depending on the dataset, input features may include:

- Age
- Sex
- Chest pain type
- Resting blood pressure
- Cholesterol level
- Fasting blood sugar
- Resting electrocardiographic results
- Maximum heart rate
- Exercise-induced angina
- ST depression

The target variable represents the presence or absence of heart disease.

## Project Workflow

1. Import the required Python libraries.

|---|---:|
